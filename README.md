# Good Bug or Bad Bug?

A free, one-page checker for 29 common garden insects — friend, pest, or it-depends — with plain-language ID cues and organic-first advice. Live at https://fscholtesdowd.github.io/good-bug-bad-bug/

Second page: [`beneficial-insects/`](https://fscholtesdowd.github.io/good-bug-bad-bug/beneficial-insects/) — which flowers attract which good bugs, sourced from Penn State Extension and University of Wisconsin Horticulture Extension.
